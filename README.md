# Frontend App
create front end app using react vite 
1. npm create vite@latest
2. after successfully creating app i move inside src folder
3. inside src folder i create two folder one for component and other for context ( global state )
4. in component folder i create four file (TodoFilter.jsx, TodoForm.jsx, TodoItem.jsx, TodoList.jsx)
5. in context folder create file todoContext.jsx 
6. in todoContext.jsx file i create custom hook for easy providing state and function across the app
